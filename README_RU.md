[**▶ Открыть текущую веб-версию**](https://stanleyll0yd.github.io/dots/)

**Точки** переносят лист бумаги в клетку и две цветные ручки в браузер. Игроки ставят точки на пересечения сетки и строят замкнутые цепочки из соседних точек вокруг соперника. Завершённые захваты обводятся и получают лёгкую штриховку.

Текущая версия исходников: **0.7.0** · классические расширенные правила окружений + локальная игра вдвоём + компьютерный соперник с четырьмя уровнями + обратимая партия + практически неограниченное поле + PWA/доступность

## 🎯 Правила

1. По умолчанию первыми ходят красные.
2. Игроки по очереди ставят по одной точке на свободное разрешённое пересечение сетки.
3. Каждые две последовательные точки контура должны находиться на соседних пересечениях: ровно в одном шаге по горизонтали, вертикали или диагонали.
4. Последняя точка контура соединяется с первой по тому же правилу одного шага.
5. Замкнутая цепь становится окружением, если внутри находится хотя бы одна точка соперника.
6. Захваченные точки соперника идут в счёт окружившему игроку.
7. Замкнутая пустая область — **домик** и не приносит очков, пока пуста. Если соперник входит в домик и этим же ходом не завершает собственное результативное окружение, домик активируется как захват.
8. Активное окружение соперника можно окружить снова. Полностью окружённые чужие захваты деактивируются, удерживаемые ими точки освобождаются, а счёт заново выводится из активного состояния.
9. Преимущество определяется количеством точек соперника, которые остаются захваченными.

Полная спецификация правил и статус реализации находятся в [`docs/PRODUCT.md`](docs/PRODUCT.md).

## 🤖 Компьютерный соперник

Выберите **«Против компьютера»** в переключателе режима. Вы играете **красными**, компьютер — **синими**. Обычный режим **«Два игрока»** сохранён. В компьютерном режиме доступны четыре уровня сложности:

| Сложность | Поведение |
| --- | --- |
| **Лёгкий** | Быстрая оценка собственного хода без просмотра ответа соперника. |
| **Обычный** | Просматривает ограниченный ответ игрока и выбирает лучший худший результат. Используется по умолчанию. |
| **Сложный** | После каждого рассмотренного ответа игрока дополнительно просчитывает свой следующий ход. |
| **Эксперт** | Добавляет ещё один ограниченный ответ игрока и использует самый широкий бюджет кандидатов. |

Компьютерный соперник полностью локальный и работает без сети. Он не использует сервер, внешний API, ML-модель, аналитику или случайность. `src/game/ai.ts` получает авторитетный `GameState`, а каждый рассматриваемый ход проверяется через то же игровое ядро, что и ход человека.

Все четыре уровня используют одинаковые правила, генерацию допустимых кандидатов и оценку позиции. Меняется только ограниченная ширина и глубина поиска. По мере роста партии бюджеты автоматически уменьшаются, а повторно встречающиеся в текущем расчёте позиции переиспользуются через временный transposition cache.

Немедленные захваты остаются приоритетными на всех уровнях. Начиная с «Обычного» ИИ явно учитывает ответ игрока; «Сложный» и «Эксперт» видят короткие многоходовые атакующие и защитные последовательности. Одинаковая позиция, уровень и параметры всегда дают одинаковый ход.

Переключение режима или сложности не очищает текущую партию. Если включить режим против компьютера, когда ход уже за синими, компьютер сразу берёт этот ход на себя. В режиме против компьютера **Undo** при наличии пары ходов отменяет и ход компьютера, и предшествующий ход человека, возвращая к предыдущей точке принятия решения.

Старые настройки режима из версии 0.6.0 автоматически мигрируют на уровень **«Обычный»**. Подробности — в [`docs/AI.md`](docs/AI.md).

## 🖱 Навигация по полю

- **Клик / касание** по пересечению ставит точку.
- **Перетаскивание** одним указателем двигает поле; порог движения отделяет постановку от pan.
- **Колесо мыши / трекпад** масштабирует относительно указателя.
- **Щипок двумя пальцами** масштабирует и перемещает поле относительно движущегося центра жеста.
- **Клавиатура:** сфокусируйте поле, стрелками перемещайте курсор по пересечениям, **Enter / Пробел** ставит точку, **+ / -** меняют масштаб.
- Viewport восстанавливается отдельно от партии. Новая игра возвращает поле к `(0, 0)` и масштабу 100%.

Перемещение камеры не меняет игровые координаты. И указатель, и клавиатурный курсор передают в игровое ядро только целое пересечение сетки.

## ♿ Доступность и мобильные устройства

- поле управляется с клавиатуры и имеет инструкции/живые объявления для screen reader;
- skip-link переводит фокус прямо на игровое поле;
- основные элементы имеют мобильный размер касания и заметный keyboard focus;
- мобильная компоновка учитывает safe areas, вырезы экрана, динамическую высоту viewport и установленную PWA;
- отдельно обработаны тёмная тема, forced-colors и `prefers-reduced-motion`;
- DPR Canvas ограничен сверху для защиты памяти на сверхплотных экранах;
- режим, уровень сложности, состояние «компьютер думает» и выбранный компьютером ход доступны через тот же доступный status/live путь.

## 📦 PWA и офлайн

Оболочка приложения предварительно кэшируется для запуска без сети. Партия, viewport, выбранный режим и сложность ИИ хранятся локально и не зависят от сети или service worker.

Когда готова новая версия, «Точки» предлагают применить обновление, а не молча перезагружают активную партию. Проверка обновлений выполняется после восстановления сети, при возвращении приложения на передний план и периодически во время работы. Production build проверяет наличие manifest, service worker, иконок установки и mobile icon linkage.

## 🛠 Разработка

Требования: Node.js 22+ и npm.

```bash
git clone https://github.com/StanleyLl0yd/dots.git
cd dots
npm install
npm run dev
```

Проверка:

```bash
npm test
npm run build
```

`npm run build` включает проверку TypeScript, production Vite/PWA build и контроль сгенерированных PWA-артефактов.
