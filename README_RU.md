**Точки** переносят лист бумаги в клетку и две цветные ручки в браузер. Игроки по очереди ставят точки на пересечения сетки. Когда корректный контур из соседних точек действительно замыкается вокруг точек соперника, захваченная область обводится и получает лёгкую штриховку.

Текущая версия исходников: **0.5.0** · полные локальные правила окружений + обратимая партия + практически неограниченное поле + усиленные PWA/доступность · GitHub Pages опубликован

## 🎯 Правила

1. По умолчанию первыми ходят красные.
2. Игроки по очереди ставят по одной точке на свободное разрешённое пересечение сетки.
3. Каждые две последовательные точки контура должны находиться на соседних пересечениях сетки: ровно в одном шаге по горизонтали, вертикали или диагонали. Пропуски и длинные отрезки запрещены.
4. Последняя точка контура также должна быть соседней с первой, замыкая цепь.
5. Замкнутая цепь становится окружением, если внутри находится хотя бы одна точка соперника.
6. Захваченные точки соперника идут в счёт окружившему игроку.
7. Замкнутая пустая область — **домик** и не приносит очков, пока пуста. Если соперник входит в домик и этим ходом не завершает собственное результативное окружение, домик активируется как захват.
8. Активное окружение соперника можно окружить снова. Полностью окружённое чужое окружение деактивируется, ранее захваченные им свои точки освобождаются, а счёт пересчитывается по текущему набору активных окружений.
9. Преимущество определяется количеством точек соперника, которые остаются захваченными.

Полная спецификация правил и статус реализации находятся в [`docs/PRODUCT.md`](docs/PRODUCT.md).

## 🖱 Навигация по полю

- **Клик / касание** по пересечению ставит точку.
- **Перетаскивание** одним указателем двигает поле; порог движения отделяет клик/тап от pan.
- **Колесо мыши / трекпад** масштабирует относительно указателя.
- **Щипок двумя пальцами** масштабирует и перемещает поле относительно движущегося центра жеста.
- **Клавиатура:** сфокусируйте поле, стрелками перемещайте курсор по пересечениям, **Enter / Пробел** ставит точку, **+ / -** меняют масштаб.
- Viewport восстанавливается после перезагрузки отдельно от партии. Новая игра возвращает поле к `(0, 0)` и масштабу 100%.

Перемещение камеры не меняет игровые координаты. И указатель, и клавиатурный курсор передают в игровое ядро только целое пересечение сетки.

## ♿ Доступность и мобильные устройства

- поле полностью управляется с клавиатуры и имеет инструкции/живые объявления для screen reader о перемещении курсора и результате постановки точки;
- skip-link переводит фокус клавиатуры прямо на игровое поле;
- основные кнопки имеют мобильный размер области касания и заметный keyboard focus;
- мобильная компоновка учитывает вырезы/безопасные зоны экрана, динамическую высоту viewport и режим установленной PWA;
- отдельно обработаны тёмная тема, forced-colors и `prefers-reduced-motion`;
- DPR backing-buffer Canvas ограничен сверху, чтобы сверхплотные экраны не создавали непропорциональный расход памяти.

## 📦 PWA и офлайн

Приложение устанавливается как PWA, а его оболочка предварительно кэшируется для запуска без сети. Сохранённая локальная партия остаётся доступной офлайн, потому что игровое состояние не зависит от service worker и сети.

Когда готова новая версия, «Точки» **предлагают применить обновление**, а не молча перезагружают текущую партию. Проверка обновлений выполняется после восстановления сети, при возвращении приложения на передний план и периодически во время работы. Production build дополнительно проверяет наличие manifest, service worker, иконок установки и mobile icon linkage.

## ✨ Что работает сейчас

- полное локальное игровое ядро для двух игроков отдельно от Canvas;
- строгая топология соседних точек в 8 направлениях, домики, множественные окружения, окружение окружения, освобождение и производный счёт;
- контур, полупрозрачная заливка, лёгкая штриховка и запрет постановки внутри активного захвата;
- точный Undo одного хода, подтверждаемая новая игра, версионированный журнал ходов и детерминированное восстановление через replay;
- практически неограниченный pan/zoom viewport для мыши, трекпада, touch/pinch и клавиатуры;
- отдельное валидируемое сохранение viewport и ограниченная видимой областью отрисовка;
- screen-reader/live-status, focus-visible, safe-area mobile UI, reduced-motion и forced-colors;
- явный offline/update lifecycle PWA с подтверждением обновления пользователем;
- исправленная геометрия масштабируемой/PWA-иконки, соответствующая правилам пересечений и соседства самой игры;
- проверка PWA/offline-артефактов после production build;
- регрессионные/stress-тесты топологии, сохранений, длинной истории, больших viewport-трансформаций и ограниченной отрисовки 8K-поля;
- русский интерфейс при наличии русского языка в браузере/системе, иначе английский;
- CI, автоматическая публикация GitHub Pages, автоматические GitHub Releases и proprietary-лицензия All Rights Reserved.

Версия **0.5.0** завершает запланированный этап browser/PWA/accessibility hardening. Основные локальные правила, обратимая партия, навигация, сохранение, офлайн-оболочка и доступный путь управления реализованы; дальше — реальное тестирование на устройствах/сложных позициях и при желании более высокий уровень функций, например ИИ.

## 🛠 Разработка

Требования: Node.js 22+ и npm.

```bash
git clone https://github.com/StanleyLl0yd/dots.git
cd dots
npm install
npm run dev
```

Проверка:

```bash
npm test
npm run build
```

`npm run build` включает проверку TypeScript, production Vite/PWA build и контроль фактически сгенерированных manifest/service worker/install assets.
