Политика конфиденциальности Dots

Действует с 1 сентября 2026 года.

Какие данные собирает приложение

Android-приложение Dots не требует регистрации и не собирает, не передаёт и не продаёт персональные данные пользователей. В приложении нет аналитики, рекламы, трекеров, аккаунтов, серверной синхронизации и сторонних SDK для сбора данных.

Локальные данные

Текущая партия, история ходов, положение игрового поля, выбранный режим и сложность компьютера сохраняются только локально на устройстве пользователя. Эти данные нужны исключительно для работы игры и не отправляются разработчику.

Сеть и внешние ссылки

Основная функциональность Android-приложения работает без сети. По явному действию пользователя приложение может открыть страницу проекта на GitHub во внешнем браузере. После перехода действуют правила конфиденциальности соответствующего внешнего сервиса.

Веб-версия

Веб-версия Dots размещена на GitHub Pages. При обращении к GitHub Pages сам хостинг может обрабатывать технические сведения в соответствии со своими правилами. Разработчик Dots не получает эти сведения через приложение и не использует собственную аналитику.

Дети

Приложение не запрашивает возраст и не собирает персональные данные детей или взрослых.

Изменения политики

При существенном изменении способа обработки данных эта страница будет обновлена одновременно с соответствующим изменением приложения.
